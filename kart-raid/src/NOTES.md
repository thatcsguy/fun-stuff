### G.fx (all pooled, no per-frame allocation)
- `burst(type, pos, {count, color, color1, tier, scale, speed, spread, dir})`, `emit(type, pos, dir, count, opts)` — count may be fractional (rate*dt), remainder accumulates per `opts.key || type`. `fx.presets` lists types: driftSpark, tireSmoke, boostFlame, wallSpark, hit, boltImpact, ember, lavaSplash, steam, chrome, lightning, starDust, ghostShatter, gold, comet, firework, explosion, mote, dust, graze, dashTrail, fizz, tierUp, heal, geyser; plus `burst('shockwave')` and `burst('lightningStrike')`. `opts.tier` (1-3) picks tier color.
- `bolt(from, targetGetter, {color, tier, crit, speed=90, delay, width, arc, onHit(pos,bolt), onFizzle})` — getter re-evaluated every tick (homing); returns null target → fizzle. Glowing head + ribbon trail + impact burst (fx does its own impact sparks).
- `ribbon({color, width, glow, alpha})` → handle `{push(v3), clear(), setColor(c,g), setAlpha, setWidth, release()}` (16 user slots; for ghost trails, light bridge, etc).
- `lightning(fromV3, toV3, {color, width, life=0.18, branches=2, jag, glow})`.
- `shockwave(pos, {color, radius, r0, dur, thick, alpha, glow, normal, lift})` (flat ring; pass `normal` for vertical rings).
- `shards(meshOrPos, count, color, {speed, size, heat, life, gravity, radius})` — 400 tetra pool; mesh → spawns over its world bbox, size scales with bbox.
- `dmgNumber(pos, n, style)` styles normal|weak|crit|player|heal|flux|graze|gold; `callout3D(pos, text, style, {scale, rise, life})` (A-Z 0-9 + - ! . % x).
- `flash(color, amt, durSec)` → delegates to `G.post.flash` (converts dur to decay). `bloomPulse(add, durSec)` → `G.post.bloomPulse`. `speedLines(k)` (3D streaks; also auto from G.kart.speed; hidden on low tier).
- `fx.mats.glow(color, intensity, {additive, opacity, side})` (cached MeshBasic, >1 blooms), `fx.mats.fresnel(color, intensity, power, {base, side})` (additive rim, instancing-aware), `fx.mats.energy(color, intensity, scroll)` (animated additive bands, uses uv). `fx.uniforms.uTime/uBeat` shared. `fx.TIER_COL`.
- **Auto event reactions** (set `G.fx.auto=false` to disable): `boss:damaged` (needs `pos`) → damage number (so COMBAT/KART should NOT also call dmgNumber for boss damage); `kart:hit` → red number + hit sparks + flash; `kart:graze` → ring + "GRAZE +N" pop; `kart:tier` ring; `kart:perfect`; `kart:dash`; `kart:comet` launch/impact (huge gold burst, rings, flash, bloom); `kart:wreck` explosion+shards; `kart:land`; `boss:stagger on` gold burst at `G.boss.root`; `boss:castEnd interrupted` violet burst; `boss:phase` flash; `boss:enrage` → sky enrage tint.
- `fx.stats()` for tests.

### G.sky
- `set(name, {axis?, env?=true})` — 'ember'|'storm'|'void'|'warp'|'title'. Inverted sphere following the camera (r = min(900, far*0.9)), plus one GPU-animated ambient Points layer (ember: 600 rising embers; storm: wind motes; void/title: twinkling stars; warp: streaks). **Also sets `scene.environment` to a PMREM of the sky shader** (overrides `G.makeEnv`, which track calls just before; pass `env:false` to keep core's). `envMap(name)` cached.
- storm: random lightning every 4-9 s (sky flash, far bolt, exposure +0.3 for ~80 ms, emits **new event `sky:lightning` {dir}** → audio plays thunder 0.5 s later). `sky.lightning(dir?)` manual.
- `setEnrage(k)`, `setDawn(k)` (storm → dawn clear for B2 death; void → nebula gains color for B3 finale). `sky.uniforms` exposed (uTime, uBeat, uEnrage, uFlash, uDawn, uSpeed, uAxis). warp axis defaults to camera forward at set() time; pass `{axis}` = warp straight direction.
- Floating rock islands (storm) and the B3 central black hole/accretion disk are NOT in the sky — boss scenery owns them. The void sky has a distant vortex + 2 galaxies.

**API notes / deviations**

- `G.boss.phase` is 0-based; events carry a 1-based `phase`. `boss:phase` is NOT emitted for the initial phase (avoids a white flash at fight start).
- `boss:dead` fires immediately; `fight:end {win:true}` fires after `def.boss.deathDur` (3.4 s for boss 1).
- `G.combat`: setupBoss, startFight(n,{phase}), endFight, retryCheckpoint, setPhase(p1) (no-op if already in it), setBossHP, killBoss, forceStagger, triggerAttack, listAttacks, state, telegraphs, clearHazards, stats, bestTarget, damageBoss, hitPlayer, wipe, dps.

- Road band alpha: telegraph bands are written at 0.8x and zones default to 0.6x (the track band shader is very emissive; wide bands bloomed the screen out). Long permanent zones should pass `alpha` ~0.3-0.45.
- Boss 1 deviations: P2 flood is on the east curve inner half; spill uses track halves; heatwave inner circle at d=-3.5; stomp = world ring + following band telegraph; difficulty is read from `G.difficulty` or `G.settings.difficulty`.
